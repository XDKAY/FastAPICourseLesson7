# FastAPICourseLesson7

# Задание по программированию с углублением в тему:
Это задание продвинутого уровня. Оно предполагает изучение дополнительных материалов, которые помогут вам найти решение. Прочитайте предложенные источники, разберитесь с новой информацией и попробуйте применить её на практике.

Расширьте приложение FastAPI, добавив валидацию отзывов и запрет на использование нежелательных слов. Новая версия конечной точки /feedback должна принимать JSON с отзывом, проверять корректность и сохранять его.

1. Определите Pydantic модель с именем Feedback со следующими ограничениями:

name — строка, обязательное поле, от 2 до 50 символов
message — строка, обязательное поле, от 10 до 500 символов
2. Добавьте кастомную валидацию поля message, которая будет отклонять отзывы, содержащие недопустимые слова: "редиска", "бяка", "козявка" (в любых падежах). Если слово найдено — выбрасывайте ValueError с сообщением "Использование недопустимых слов".

3. Создайте POST-маршрут /feedback, который:

Принимает JSON по модели Feedback
При успехе сохраняет данные в список feedbacks
Возвращает JSON с сообщением: {"message": "Спасибо, {name}! Ваш отзыв сохранён."}
Пример запроса:

{
    "name": "Анна",
    "message": "Этот курс заставляет меня напрячься, но я все равно его пройду!"
}


                  
Пример ответа:

{
    "message": "Спасибо, Анна! Ваш отзыв сохранён."
}


                  
Пример некорректного запроса:

{
    "name": "А",
    "message": "тут сплошные редиски кругом, житья совсем не дают"
}


                  
Пример ответа (HTTP 422):

# структура может отличаться в зависимости от версии пидантика
{
  "detail": [
    {
      "type": "string_too_short",
      "loc": [
        "body",
        "name"
      ],
      "msg": "String should have at least 2 characters",
      "input": "А",
      "ctx": {
        "min_length": 2
      }
    },
    {
      "type": "value_error",
      "loc": [
        "body",
        "message"
      ],
      "msg": "Value error, Использование недопустимых слов",
      "input": "тут сплошные редиски кругом, житья совсем не дают",
      "ctx": {
        "error": {}
      }
    }
  ]
}


                  
Проверьте реализацию через curl, Postman или любой другой инструмент, отправляя как корректные, так и ошибочные отзывы.

Материалы для изучения
Документация Pydantic 2.0: валидаторы и документация: поля
Валидация данных в FastAPI (Habr)
Для успешного выполнения вам пригодятся знания о min_length, max_length и @field_validator, а также о регулярных выражениях в Python.


# Запуск

1. `git clone git@github.com:XDKAY/FastAPICourseLesson7.git`
2. `cd FastAPICourseLesson7`
3. `uv venv`
4. `source .venv/bin/activate`
5. `uv sync`
6. `uvicorn app.main:app --reload`
7. http://127.0.0.1:8000
